# textstats

Небольшая утилита для подсчёта статистики текста: количество слов,
символов и самых частых слов. Используется как учебный проект в
лабораторной работе по Git.

## Установка

Python 3.10+ и никаких внешних зависимостей:

```bash
python -m textstats.cli sample.txt
```

## Пример вывода

```bash
$ python -m textstats.cli notes.md
words: 9
chars: 53
top: # = 1
```
